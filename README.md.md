# Моделирование влияния электрических помех на сигнал

## Описание

Скрипт моделирует влияние периодической электрической помехи и
случайного белого шума на полезный сигнал. В качестве полезного сигнала
используется синусоида частотой 10 Гц, а в качестве периодической помехи
--- синусоида частотой 50 Гц.

Для уменьшения влияния помех применяется фильтр скользящего среднего.
Скрипт сравнивает характеристики сигнала до и после фильтрации, выводит
численные результаты и строит график.

**Важно:** программа выполняет компьютерное моделирование. Полученные
значения не являются результатами физических измерений.

## Требования

-   Python 3.8 или новее;
-   NumPy;
-   Matplotlib.

## Установка библиотек

Откройте терминал и выполните:

``` bash
python -m pip install numpy matplotlib
```

## Запуск

Перейдите в каталог с файлом и выполните:

``` bash
python моделирование_электрических_помех.py
```

После запуска программа выведет в консоль результаты расчётов для
нескольких значений амплитуды помехи, а затем откроет окно с графиком.

## Принцип работы

1.  Формируется полезный синусоидальный сигнал частотой 10 Гц.
2.  К нему добавляются периодическая помеха частотой 50 Гц и белый шум.
3.  Амплитуда периодической помехи последовательно изменяется: 0.1,
    0.25, 0.5, 0.75 и 1.0.
4.  К исходному сигналу и зашумлённому сигналу применяется фильтр
    скользящего среднего с окном 20 отсчётов.
5.  Для каждого значения амплитуды рассчитываются:
    -   **SNR до фильтрации** --- отношение мощности полезного сигнала к
        мощности помех;
    -   **SNR после фильтрации** --- отношение мощности сглаженного
        эталонного сигнала к мощности остаточной ошибки;
    -   **RMSE до фильтрации** --- среднеквадратичная ошибка
        зашумлённого сигнала;
    -   **RMSE после фильтрации** --- среднеквадратичная ошибка
        результата фильтрации относительно исходного полезного сигнала.
6.  Для примера с амплитудой периодической помехи 0.5 строится график
    полезного сигнала, сигнала с помехой и результата фильтрации.

## Основные параметры

Параметры моделирования задаются в начале Python-файла:

  Параметр                Значение Назначение
  ------------------ ------------- ------------------------------------
  `fs`                     1000 Гц Частота дискретизации
  `duration`                   2 с Длительность моделирования
  `f_signal`                 10 Гц Частота полезного сигнала
  `f_interference`           50 Гц Частота периодической помехи
  `noise_std`                 0.20 Стандартное отклонение белого шума
  `window`             20 отсчётов Размер окна скользящего среднего

Для изменения условий эксперимента можно отредактировать эти значения
непосредственно в исходном коде.

## Результаты

В консоль выводятся пять наборов результатов. В каждой строке указаны
амплитуда периодической помехи, SNR до и после фильтрации, а также RMSE
до и после фильтрации.

График отображает первые 250 отсчётов моделирования, чтобы различия
между исходным, зашумлённым и отфильтрованным сигналами было удобнее
рассмотреть.

## Ограничения модели

-   Рассматривается один полезный сигнал --- синусоида.
-   Периодическая помеха представлена синусоидой частотой 50 Гц.
-   Дополнительно учитывается случайный белый шум.
-   Для фильтрации используется простой фильтр скользящего среднего.
-   Модель не учитывает все особенности реальных электрических цепей и
    каналов передачи сигналов.
